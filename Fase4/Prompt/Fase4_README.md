# Phase 4: Real-Time IoT Data Processing

## Overview

Once agricultural sensor data has been stored in the time-series database, it is necessary to perform data cleaning, transformation, and enrichment processes before using the data for analysis or prediction.

In digital agriculture systems, this processing allows:

- Removing erroneous values
- Transforming measurement units
- Calculating agroclimatic indicators
- Generating new derived variables

In this phase, the IoT Gateway will be used to perform real-time data processing before storing or analyzing the data.

This phase will implement the data processing stage that receives simulated sensor data and stores it in a specialized time-series database. The processing stage will allow cleaning, transforming, and storing data coming from agricultural sensors.
