# Phase 5: Definition of Agronomic Thresholds and Alert Generation

## Overview

Some agroclimatic variables can reach values that negatively affect crop growth and development.

In this phase, agronomic thresholds will be defined to detect situations such as:

- Water stress
- Excess radiation
- Extreme temperatures

The designed and simulated system must be capable of generating alerts when these thresholds are exceeded.

---

# Learning Outcome

Design and simulate an alert system based on critical agroclimatic conditions generated by agroclimatic variables that reach values outside the permitted range.

---

# Deliverable

Alert configuration that includes:

- Description of the monitored variables and their operating range
- Definition and explanation of threshold values and how they affect the crop
- Generation of alarms and notifications through Email, SMS, WhatsApp, etc.
