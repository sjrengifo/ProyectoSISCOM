# Final Phase: Phase 7: Visualization and Dashboard

## Overview

In the final phase, an agricultural monitoring dashboard will be built to visualize in real time the agroclimatic variables coming from the simulated sensors.

The dashboard will allow users to observe the status of the plots, detect anomalies, and analyze climatic trends.

---

# Learning Outcome

Design a dashboard for agricultural monitoring based on IoT data.

---

# Deliverable

Functional dashboard that includes:

- Visualization of the most important agroclimatic variables for the crop
- Plot monitoring
- Indicators and alerts
